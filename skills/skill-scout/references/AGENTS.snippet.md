Before starting a new substantive task, use $skill-scout from the installed
skills. If it is not in the session catalog, read
`.agents/skills/skill-scout/SKILL.md` when that file exists.
First check whether available skills already cover the task. For a real
capability gap, do one short search across multiple relevant sources, review
actual candidate skills, and recommend at most three with their task-specific
benefits, source links, and installation commands. Use the user's language.
Do not install or change settings without the user's applicable authorization.
Continue the original task using current capabilities while optional
recommendations await a decision. Skip trivial requests, small follow-ups,
already-covered tasks, and repeated or declined suggestions in this task.
If Scout is unavailable, proceed with the available capabilities.
