Before starting a new substantive task, use $skill-scout from the installed
skills. If it is not in the session catalog, read
`.agents/skills/skill-scout/SKILL.md` when that file exists.
First check whether available skills, built-in tools, connected MCP servers,
or plugins already cover the task. For a real capability gap, do one short
search across relevant skill, MCP, and plugin sources. Review actual candidates
and recommend at most three additions in total with their type, task-specific
benefit, source, connection state, and installation or connection steps.
Avoid duplicate recommendations when a plugin includes the needed skill/MCP.
Use the user's language. Do not install, connect, or change permissions/settings
without the user's applicable authorization.
Continue the original task using current capabilities while optional
recommendations await a decision. Skip trivial requests, small follow-ups,
already-covered tasks, and repeated or declined suggestions in this task.
If Scout is unavailable, proceed with the available capabilities.
